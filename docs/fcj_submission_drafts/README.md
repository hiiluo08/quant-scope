# FCAJ Submission Drafts

Các file trong thư mục này là source drafts để chuyển sang workshop Hugo cá nhân sau khi clone và đọc `fcj-workshop-template`.

## Quy tắc sử dụng

1. Không copy nguyên workshop sample; rewrite bằng QuantScope và evidence thật.
2. Giữ cấu trúc nội dung tương đương giữa tiếng Việt và tiếng Anh.
3. Thay mọi `PLACEHOLDER` bằng dữ liệu thật trước khi publish/nộp.
4. Không đưa secret, access key, account ID nhạy cảm, public IP riêng, raw data/model artifact vào workshop.
5. Worklog là công việc đã làm/evidence thực tế, không được dùng plan như bằng chứng completed work.
6. Sau khi clone template, map drafts vào exact Hugo content paths được README/config template chỉ định, sau đó chạy local build trước.
